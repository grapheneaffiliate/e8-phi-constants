## Reproduction

```bash
cd data
gp -q gen_disc_ordered.gp > disc_ordered.csv   # ~20 min, 4 threads
gp -q gen_reg_ordered.gp  > reg_ordered.csv    # ~2 h,   4 threads
gp -q gen_disc_window.gp  > disc_window.csv    # ~5 min, 4 threads
cd ..
python3 analysis/build_db.py                   # -> data/quadratic_fields.sqlite
python3 analysis/compare.py                    # -> data/summary/*.csv
```

The class groups are computed by `quadclassunit`, which uses Bach's
bound and is therefore conditional on GRH. `data/grh_spotcheck.gp`
recomputes a sample with `bnfinit` + `bnfcertify`, which is
unconditional; see REPORT.md for the result.
